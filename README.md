# CPSU Compass

A responsive Vue 3 + Vite demo for the CPSU San Carlos Campus Guidance, Counseling and Testing Center.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Demo limitations

This is a front-end prototype. Login accepts any non-empty ID/email and password; appointments, mood check-ins, concerns, and survey responses are stored in the current browser only. No email, SMS, or live notifications are sent. Do not enter real student or counseling information.

Before launch, replace the marked contact details, counselor profiles, office location, emergency information, announcements, and sample forms with verified campus content. A production system needs a secure backend, database, authentication, role-based authorization, and privacy review before handling student data.
